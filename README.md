#Istruzioni di compilazione con g++ e cmake gia installati su ambiente Linux Ubuntu/Mint*

1) Creare il file NomeCognome.cpp con il proprio nome e cognome

2) Nel file Makefile, nella variabile Nome, sostituire NomeCognome con il nome dato al file nel passo precedente

3) Cliccare con il tasto destro del mouse in una parte vuota della finestra e selezionare dal menu contestuale la voce "Apri nel terminale" o "Open in terminal"

4) Compilare il programma digitando il comando "make" che produce l'eseguibile

5) Eseguire il programma

Es.:
1) NomeCognome.cpp -> AndreaIannaccone.cpp

2) Nel Makefile
Nome = AndreaIannaccone

3) Al prompt dare il comando make che produce l'eseguibile AndreaIannaccone

4) Per eseguire il programma, al prompt: ./AndreaIannaccone
